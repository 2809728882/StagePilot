# StagePilot 产品需求

## 产品目标

让演示人员只用手机即可稳定控制 Windows 主屏，在程序、窗口和视频之间切换时持续展示有意义的画面，避免暴露桌面操作和窗口准备过程。

## 核心用户

- 展厅与数字大屏运营人员
- 发布会、路演和会议主持人
- 培训讲师与课堂教师
- Unity 交互展示项目实施人员
- 企业宣传视频播放人员

## 核心流程

1. 电脑端首次启动并完成准备检查。
2. 设置连接密码、视频文件夹和快捷程序。
3. 手机通过同一局域网扫码连接。
4. 手机选择程序、当前窗口或视频。
5. 电脑保持上一画面，准备目标内容并完成切换。
6. 发生错误时保留原画面、回滚窗口状态并显示可理解的错误信息。
7. 演示结束后由手机退出管控，电脑端恢复被临时调整的窗口状态。

## 已实现需求

### 连接与认证

- 局域网二维码连接
- PBKDF2 派生验证值与一次性挑战登录
- 修改密码后轮换令牌并断开旧连接
- 登录失败限速

### 程序与窗口

- 添加任意 Windows 可执行程序
- 自动发现常用浏览器
- 枚举、切换和关闭当前窗口
- 目标窗口恢复、最大化与前台验证
- 置顶 Unity 窗口的让出、恢复和异常退出恢复

### 视频

- 扫描指定文件夹
- 手机视频列表
- 双播放器预加载
- 全屏播放、暂停、继续、跳转和音量控制

### 演示连续性

- 当前主屏截图保持
- 目标内容准备完成后揭示
- 等待时间可配置
- 错误时继续保留原画面
- 安全黑屏

### 可运维性

- 启动准备状态检查
- 当前状态、版本、视频数和窗口数展示
- 损坏配置回退与原文件保留
- 自动化单元测试和 Windows 原生窗口测试

## 后续路线图

### 近期

- 多网卡地址选择与二维码切换
- 快捷程序重命名、排序和启动参数编辑
- 本地诊断日志导出与隐私清理
- 应用图标、安装签名和 GitHub Release 自动构建

### 中期

- 多显示器目标选择
- 演示流程编排与一键下一幕
- 视频封面、时长和播放进度展示
- 开机启动与托盘快捷设置

### 长期

- 可选 HTTPS 局域网连接
- 控制端角色与只读观察模式
- 插件式播放器和窗口适配策略
