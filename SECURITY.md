# Security Policy

Security fixes are applied to the latest version on the default branch.

Please use GitHub private vulnerability reporting for security issues. Include the affected version, reproduction steps, expected behavior and observed behavior. Do not place credentials, pairing tokens, private media or personal data in a public Issue.

StagePilot is designed for a trusted local network. Use a strong connection password, keep Windows and browsers updated, and do not expose the control port directly to the public Internet.
